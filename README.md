# 🏥 CareConnect - Professional B2B Healthcare SaaS

CareConnect is a state-of-the-art Healthcare Management System designed for clinics and hospitals to manage patient records, clinical analytics, and administrative tasks with a premium, high-trust user experience.

---

## ✨ Features & Capabilities

### 🛡️ Secure Clinical Authentication
Experience a professional, secure entry point designed with high-trust aesthetics.
- **Glassmorphism Design**: High-end visual hierarchy for professional medical environments.
- **Persistent Sessions**: Your session remains active across tab closes and refreshes within a 1-hour security window.
- **Demo Access**: Use `demo@careconnect.com` / `password123` to explore the full suite of tools.

### 📊 Clinical Dashboard
Get a high-level overview of your facility’s health at a glance.
- **Real-time Metrics**: Monitor Total Patients, Active Cases, and Appointments.
- **Patient Volume Analytics**: Dynamic charting powered by Recharts for weekly traffic analysis.
- **Clinical Alerts**: Instant notifications for missing lab results, new registrations, and pharmacy pickups.

### 📋 Patient Management
Manage the full patient lifecycle with absolute precision.
- **Dynamic Views**: Switch between High-Density List view and Visual Grid view.
- **Clinical Details**: Tracks Specialty, Primary Attending Physician, and Admission Priority.
- **Full CRUD Support**: Securely add and remove patient records with clinical intake forms.
- **Advanced Filtering**: Search by name, condition, or specialty instantly.

## 🛠️ Technology Stack

- **Frontend**: React 18 + TypeScript (Strict Mode)
- **State Management**: Zustand with Persistence Middleware
- **Routing**: React Router 6 (with Protected Routes)
- **Styling**: Tailwind CSS v4 (Modern Fluid Design)
- **Visualization**: Recharts (Custom Medical Theming)
- **Notifications**: PWA Service Worker API
- **Auth Service**: Firebase (Mocked for Demo Environment)

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v16 or higher)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Installation Steps

1. **Clone the repository**:
   ```bash
   git clone https://github.com/your-username/careconnect-saas.git
   cd careconnect-saas
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Environment Setup**:
   The project is pre-configured with a **Mock Security Layer** for demonstration. No API keys are required for initial exploration.

4. **Start Development Server**:
   ```bash
   npm run dev
   ```

5. **Visit the App**:
   Navigate to `http://localhost:5173` and login with:
   - **Email**: `demo@careconnect.com`
   - **Password**: `password123`
